2. 取得する情報と使いみち

(1) 現在地(位置情報)

本アプリは、地図に現在地を表示するために、端末の位置情報を使います。位置情報の使用は、端末の設定または本アプリの確認画面で、お客様が許可した場合に限ります。許可しない場合も、地図の閲覧など位置情報を使わない機能は使えます。

本アプリを開いたときは、位置情報が許可されていれば、その時点の現在地を1回だけ当社へ送信します(下の「起動記録」)。地図を見ている間の位置の動きを、当社へ送ることはありません。

(2) 起動記録

本アプリを開くたびに、次の情報を当社の管理用サーバー(Google Apps Script および Google スプレッドシート)に送信し、記録します。

項目アプリを開いた日時 / 認証に使ったパスワード / お客様が入力したお名前または端末名 / 端末ごとの識別番号(アプリが自動で作る乱数。広告ID等ではありません) / 端末の種類(例:Android・アプリ版) / アプリの版 / 現在地(緯度・経度・誤差。許可した場合のみ)
使いみち・利用状況の把握(いつ、どの端末で使われているか)
・不正な利用や、パスワードの不正な共有の防止
・サービスの改善と、利用者へのご連絡

お名前・端末名の欄には、個人を特定しにくい名称(例:「A班のスマホ」)を入れていただいても構いません。

(3) お客様の端末の中だけで扱う情報

次の情報は、お客様の端末の中だけで扱い、当社へ送信しません。

  • お客様が開いた KML ファイルの内容(山林の区域・目印など)
  • 地図上で見ている範囲、設定、端末の識別番号と認証の状態(端末内の保存領域に保存)

3. 第三者への提供・外部サービス

  • 当社は、法令に基づく場合を除き、取得した情報を本人の同意なく第三者へ提供しません。
  • 起動記録の保管と処理には、Google LLC のサービス(Google Apps Script、Google スプレッドシート)を使います。情報は、Google が定める条件のもとで取り扱われます。
  • 本アプリの画面データは GitHub Pages から配信しています。アクセスした際、通信の記録(IPアドレス等)が GitHub 側に残る場合があります。
  • 地図の画像・標高データは、国土地理院などの配信元から取得します。地図を表示すると、表示範囲に応じた通信が配信元に届きます。この通信に、お客様の氏名など当社が記録した情報は含まれません。

4. 保管期間

起動記録は、利用を終了した後、最長で2年間保管し、その後に削除します。

5. 安全管理

起動記録は、当社の管理者だけが開けるスプレッドシートに保管します。通信は暗号化(HTTPS)されます。

6. 開示・訂正・削除のご請求

ご自身の起動記録の確認、訂正、削除を希望される場合は、上記のお問い合わせ先へご連絡ください。ご本人であることを確認のうえ、対応します。

7. 位置情報の許可の変更方法

端末の「設定」→「アプリ」→「フォレストウォーカー」→「権限」→「位置情報」から、いつでも変更できます。許可を外すと、現在地は地図に表示されず、起動記録にも位置は付きません。

8. 本ポリシーの変更

内容を変更する場合は、本ページに掲載して、お知らせします。重要な変更の場合は、アプリの画面でも、あらためて同意をお願いすることがあります。
